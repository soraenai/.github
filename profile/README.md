### Why SORAEN

Most AI assistants sound confident even when they're wrong. We build models that answer from evidence,
cite the source behind every claim, and say *"I don't know"* instead of guessing.

### Our first model: SORAEN Lite *(in development)*

| | |
|---|---|
| **Base** | Fine-tuned from the open [Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B) model (Apache 2.0) |
| **Training** | Supervised fine-tuning + preference optimisation (DPO) on 12,500+ curated, licence-checked examples |
| **Grounded answers** | Answers from your own documents with exact citations, and abstains when the answer isn't there |
| **Multimodal** | Image understanding and voice input |
| **Safety** | Red-team tested and screened by a safety classifier before release |
| **Release** | Open weights on Hugging Face, plus a hosted API and browser chat |

### How we work

- **Evidence over guesswork.** A correct "the documents don't say" beats a fluent guess.
- **Honest evaluation.** Benchmarks are decontaminated, and we publish results, losses included.
- **Safety before shipping.** A model ships only if it is not less safe than its base.
- **Open by default.** Weights, model cards and evaluation methods are public.
